# get_crypto_price Skill
Instructions:
- This skill allows you to fetch the current price of a cryptocurrency in a specified currency using the CoinGecko API.
- You can use this tool by passing a JSON input with parameters `coin_id` and `vs_currency`.
- For example, to get the price of Ethereum in USD, you would pass `{"coin_id": "ethereum", "vs_currency": "usd"}`.
